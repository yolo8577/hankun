# 两个人的故事网页 · GitHub Pages 发布

这个文件夹是可直接发布的静态网页。请把**文件夹里的内容**放到 GitHub 仓库根目录，确保 `index.html` 在仓库最外层。

1. 在 GitHub 新建一个 **Public** 仓库，例如 `hankun`。
2. 解压 `github-pages-site.zip`，把里面的 `index.html`、CSS、JS、`.nojekyll` 和 `images` 文件夹上传到仓库根目录并提交。
3. 打开仓库 **Settings → Pages**，在 **Build and deployment** 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/(root)`，然后保存。
4. 等 GitHub 完成部署。网页地址通常是 `https://你的用户名.github.io/hankun/`。也可在 Pages 设置页查看实际地址。

目前页面仍使用示例故事和示意插画；公开发布前可在 `index.html` 中替换日期、文字和图片。网页中的猫鱼照片是你提供的参考图，上传到公开仓库后任何人都能看到。
